## ⚡ Quick Setup (5 minutes)

### Step 1 — Get your FREE Gemini API Key
1. Go to: https://aistudio.google.com
2. Sign in with Google account
3. Click "Get API Key" → "Create API Key"
4. Copy the key (starts with `AIza...`)
> ✅ Completely free | No credit card | 15 requests/min

---

### Step 2 — Install and Run

```bash
# Install dependencies
pip install -r requirements.txt

# Run the app
streamlit run app.py
```

The app opens automatically at: **http://localhost:8501**

---

### Step 3 — Use the App

1. **Paste your API Key** in the sidebar
2. **Select the absent student** from the dropdown
3. **Select today's lesson** (as posted on Qatar Platform)
4. Navigate through the 5 tabs:
   - 📚 Qatar Platform → see lesson details
   - 👤 Student Profile → see NSIS level
   - 📖 Mini Lesson → generate AI lesson
   - 📝 Worksheet → generate practice exercises
   - ✅ Quiz → generate & take 5-question quiz
